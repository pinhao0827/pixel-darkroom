Brightness / 光線

亮度

讓整張影像變亮或變暗，觀察陰影與高光一起變化時，哪些細節先消失。

動手比較

125%

原圖基準 100%

原理

亮度控制會整體放大或縮小影像的色彩數值。往上拉時，暗部可能更容易辨認，燈籠的亮部卻可能先變成一片。往下拉時，巷口的陰影會先變得難以分辨。

三步練習

  1. 把亮度從 100% 慢慢拉到 145%。
  2. 在左側牆面找紋理，再看右上方燈籠的紙紋是否仍能分辨。
  3. 切回原圖，記下你開始看不清燈籠紋理的時刻。

帶走一個觀察

提亮夜景時，分別看最暗和最亮的區域。看得清陰影也要看得見亮部的層次。
