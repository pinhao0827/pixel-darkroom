Contrast / 光線

對比

放大或縮小明暗差距，找出讓畫面有層次的對比範圍。

動手比較

135%

原圖基準 100%

原理

對比調高時，偏亮的地方更亮，偏暗的地方更暗。對比調低時，兩者更接近中間亮度，黑色看起來偏灰。這個練習可以用窗邊亮面和緊鄰的暗處觀察變化。

三步練習

  1. 先降低對比，再慢慢拉過 100%。
  2. 比較店面玻璃周圍的暗處和路面的亮色倒影。
  3. 在原圖與調整間切換，找出倒影醒目、牆面仍有紋理的區間。

下次修圖時

檢查相鄰的亮面與暗面。如果輪廓更清楚但紋理一起不見，可以試著把數值往回收。
